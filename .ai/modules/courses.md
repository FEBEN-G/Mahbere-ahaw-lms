# Course Module

## Responsibilities

- Create Course
- Edit Course
- Delete Course
- Publish Course
- Monthly Release

## Features

- Course
- Modules
- Attachments
- Video Links
- PDF
- Visibility
- Release Date
- Automatic Unlock

## Business Rules

- Course belongs to Month
- Student only sees unlocked months
- Unlock occurs automatically after registration period
- Soft delete only
- Track `createdBy` / `updatedBy` timestamps
- Typical drip: 2 courses per month
