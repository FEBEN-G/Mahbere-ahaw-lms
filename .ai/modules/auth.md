# Authentication Module

## Responsibilities

- Login
- Logout
- Refresh Token
- Password Reset
- Role Authorization

## Requirements

- JWT
- Refresh Tokens
- Argon2
- RBAC
- Audit Login
- Session Tracking

## Rules

- Never store plain passwords
- Never trust client role
- Always verify permissions
- Every protected endpoint requires authentication

## Support

- Student
- Instructor
- Admin
- Super Admin
