# Assignment Module

## Student

- Download assignment
- Upload submission
- Replace submission before deadline

## Instructor

- Download submissions
- Grade
- Feedback

## Rules

- Validate file type
- Validate size
- Store in MinIO (or local adapter)
- Store metadata in PostgreSQL
- Never store files inside database
- Clearly display due dates

## Support

- PDF
- DOCX
- PNG
- JPG
