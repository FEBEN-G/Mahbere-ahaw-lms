# Instructors Module

## Responsibilities

- Instructor profile management
- Assign instructors to courses / grading scope
- Instructor directory for admin

## Business Rules

- Instructors can only grade submissions within their assigned scope
- Super Admin registers instructors and issues credentials
- Soft delete preserves historical grading audit

## Integrations

- Submissions (review queue)
- Grading (score + feedback)
- Courses (assignment ownership / visibility)
