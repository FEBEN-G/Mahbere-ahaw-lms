# Coding Standards

Prefer readability over clever code.

## Functions

- less than 40 lines

## Files

- less than 300 lines

## Classes

- one responsibility

## Methods

- one responsibility

Never nest more than three levels.

Prefer early return.

Avoid else when possible.

Meaningful variable names.

No abbreviations.

No duplicated code.

Use interfaces.

Keep controllers thin.

Avoid static utilities.

Prefer dependency injection.

Every public function requires documentation.

Every complex logic requires comments explaining WHY.

Never comment obvious code.

Write self-documenting code.
